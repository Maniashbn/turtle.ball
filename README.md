# turtle.ball
یک بازی تعاملی ساخته‌شده با زبان Python و کتابخانه Turtle که در آن بازیکن یک لاک‌پشت را با استفاده از کلیدهای کیبورد کنترل می‌کند. هدف بازی حرکت در محیط، برخورد با توپ‌ها و کسب امتیاز است. با برخورد لاک‌پشت به توپ، امتیاز افزایش پیدا می‌کند و برخورد با دیوار باعث کاهش امتیاز می‌شود. بازی دارای سیستم امتیازدهی  و صفحه‌های برد و باخت است.
